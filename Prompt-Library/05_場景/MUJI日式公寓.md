# MUJI 日式公寓

---

【場景 Environment】

Minimalist MUJI-style Japanese apartment interior.

場景設定：
極簡乾淨日式公寓、淺木色家具、象牙白或淺米白沙發、淺木地板、白色薄紗窗簾、綠色植物。

顏色規範：
室內色彩以白色、象牙白、淺米白、淡木色、低飽和自然色為主。
不可使用奶油黃家具、橘黃色地板、暖黃色燈光、焦糖色家飾。
床鋪、沙發、窗簾為象牙白或淺米白，禁止出現奶油黃色床鋪。

空間氛圍：
安靜、舒適、透明、明亮、乾淨、高級、生活感、日系電影感。
整體空間明亮通透，具有清透自然光感。

防黃規則：
不可出現黃光籠罩、橘黃色房間色調、復古泛黃感。
不可讓木質家具的反光造成整體畫面偏黃偏橘。
整體畫面色調需維持中性或微冷，禁止暖色整體偏移。

畫面不可雜亂，不要出現過多物件。
